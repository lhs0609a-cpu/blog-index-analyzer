# 두비전(DOVISION) 광고 운영 기록

## 계정

- 네이버 광고 고객번호 `4403292` · 사이트 https://dovision.co.kr (비즈채널 ELIGIBLE)
- ㈜키네스 그룹 계열. 키네스(441986)와 같은 고객 풀을 공유한다(8세 이상 자녀 학부모).
- **가맹점을 모집하는 광고주는 이 계정 하나뿐이다.** 키네스는 프랜차이즈 브랜드지만
  광고 계정에는 가맹모집 구조가 없다(캠페인 75·그룹 1,001개 중 가맹/창업/지사 계열 0).

## 광고주가 실제로 파는 것 (2026-09-16 사이트 실물 확인)

이미지전환기억법(특허 제10-1994856호) 기반 **'방법을 가르치는 학원'**이다. 특수인지능력검사로
진단하고, 글자를 장면으로 바꾸는 기억법을 가르친다. 대상은 **초·중·고 학습능력 개발**
(+ 3~8세 별도 브랜드 두비전키즈). 가맹 모델은 초기 1억 / 월 운영비 1,300~1,800만 /
본사 공급원가 매출의 22.5% / BEP 월 신규 3~4명.

### 1) 입찰이 전부 70원이다

표본 조회 결과 캠페인·그룹·키워드 입찰이 예외 없이 70원(`useGroupBidAmt=False`).
같은 날 잰 순위별 추정 입찰가는:

| 키워드 | 5위 | 1위 | 70원 대비 |
|---|---|---|---|
| 공부방창업 | 13,820원 | 19,830원 | **197배** |
| 학습클리닉 | 6,600원 | 23,350원 | 94배 |
| 난독증검사 | 2,160원 | 7,830원 | 31배 |
| 메타인지 | 770원 | 1,270원 | 11배 |
| 암기법 | 390원 | 910원 | 5.6배 |

**소진을 막는 건 예산이 아니라 입찰이다.** 키워드를 아무리 더 등록해도 70원이면 안 뜬다.

### 2) 도메인 프로파일이 파는 것과 어긋나 있었다

`relevance_keywords` 540개 중 기억·암기·공부법·인지검사 계열은 20개뿐이고,
description 은 *"유아·초등 대상 … 중고등입시·영어·예체능은 도메인 밖"*이라고 써 있었다.
실물은 초·중·고 대상 기억법 학원이다. 이 게이트로는 이번 딥리서치 결과가
등록 단계에서 통째로 `domain_skipped` 된다. → `dovision_deep_profile.py --apply`

### 3) 택소노미에 '파는 것'의 자리가 없었다

기존 중분류 27개는 사고력수학·코딩·가베·영어 위주. 기억법·공부법·집중력·학습클리닉·
난독 중분류가 아예 없었다. → `_DOVISION_TAXONOMY` 에 대분류 **학습솔루션** 6개 중분류 추가
(기억법·암기법 / 공부법·학습법 / 집중력·주의력 / 학습클리닉·검사 / 난독·느린학습자 / 성적·학습고민).
교육 중분류보다 앞에 둬야 '유아기억력'이 유아가 아니라 기억법으로 간다.

## domain_skipped 21만은 자산이 아니다

`rescore-skipped` dry-run: 50,000행 중 지금 게이트로 되살아날 것은 2,697개뿐이고
표본은 알바·자격증·부동산계산기·뮤지컬 계열이다. 2026-07 mega 시드가 '창업'을
광역으로 퍼온 잔재다. 여기를 파는 대신 새로 발굴하는 게 맞다.

## 2026-09-16 B2C 딥리서치

기존 딥리서치는 B2B(가맹모집) 축만 팠다(482개 채택). 이번엔 **학부모** 축을 판다.

- 앵커 288개 (기억법 / 공부법 / 집중력 / 성적고민 / 검사·진단 / 학습클리닉 /
  난독·학습장애 / 유아키즈 / 경쟁브랜드 / 지역×학습)
- 채널 3개: keywordstool 연관 BFS · **네이버 자동완성 BFS** · 지역×서비스 조합
- 자동완성이 압도적으로 정확하다 — 후보의 67%가 실검색량 10+ (지역 조합은 6%)

### 판정 기준에서 배운 것

이 도메인의 오탐은 전부 **부분문자열**이다. 형상**기억**합금 · 얼그레이**밀크티** ·
수능**성적**표 · 가천**대논술** · **기억력**영양제 · 강아지**기억력** · 구암**평생학습센터** ·
기아**인적성검사**. 토큰 블랙리스트로 잡으면 진짜 키워드까지 죽어서, 문맥 정규식
(`CONTEXT_OFF`)과 뜻이 둘인 브랜드 처리(`AMBIG_BRAND` + 교육 문맥 필수)를 따로 뒀다.

'학원'이라고 다 고객이 아니다. 영어회화·연기·피아노·태권도·유학원은 두비전이 가르치지 않는다.
그래서 STRONG(두비전 본질: 암기·기억·공부법·집중·인지·난독) 토큰이 없으면 컷한다 —
원장 5.4만 중 '교육 일반어일 뿐'으로 걸러진 게 1.1만이다.

## 아직 안 한 것

- 프로파일 확장·택소노미 배포·업로드·입찰 조정은 **전부 미실행**(승인 대기).
- 계정 캡 100,000 / 등록 80,495 → 남은 자리 19,505. 전량 등록은 불가하고 점수 순 상한이 필요하다.
- 학습지 계열(초등학습지·영어학습지 등)은 5위 입찰가 27,000~43,000원이다. 대교·구몬이
  다 먹는 자리라 두비전 예산으로 들어갈 곳이 아니다.

## 2026-09-16 가맹 창업 딥리서치 (광고주 지시로 축 변경)

B2C 학부모 축은 접고 **가맹점 모집**으로 방향을 바꿨다. B2C 산출물(3,727개,
`dovision_deep_*.csv`)은 가맹점이 생겨 원생을 모을 때 쓸 자산으로 남긴다.

### 기존 B2B 발굴이 엉뚱한 사람을 사고 있었다

2026-09 라운드의 482개 중 **58%가 주부부업·자격증**이었다 —
집에서하는부업(5,810) · 50대일자리(2,270) · 독서지도사자격증(2,420).
두비전 가맹은 초기 1억 + 보증금 2,500~3,000만이다. 부업을 찾는 사람이 넣을 돈이 아니다.
정작 가맹모집·상담 축은 22개 / 월검색 970뿐이었다.

교육열 높은 학부모 / 소자본 교육창업).

### 판정에서 조심한 것
- `가맹문의`·`정보공개서`에는 '교육'이 안 붙는다. 교육 토큰을 필수로 걸면 가장 비싼
  키워드를 통째로 버린다 → `FC_CORE` 우회(업종 오탐은 OFF 가 먼저 잡는다).
- `푸르넷공부방`·`생각하는황소`를 치는 사람은 차리려는 사람이다 → `BRAND_BIZ` 우회.
- `소상공인정책자금`(월 200,500)은 전업종 자금이라 교육 가맹과 무관하다. 볼륨에 속으면 안 된다.
- 부분문자열 오탐: 학원**버스**기사 · **피아노**학원매매 · **어린이집**매매 · **대학원**등록금 ·
  **성인**수학공부 · **예비창업패키지**.

### 2026-09-16 2차 — 대량 발굴 (광고주 "다 찾아서 대량으로")

1차가 1,097개에서 끝난 이유는 앵커가 231개였고, 무엇보다 **BFS 프론티어를 채택 게이트로
골랐기** 때문이다. 게이트가 엄격하면 프론티어가 작아지고, 프론티어가 작으면 더 못 번진다 —
자기 자신을 막는 루프다. 그래서 게이트를 둘로 쪼갰다.

| | 확장 게이트(BFS 프론티어) | 채택 게이트(최종 CSV) |
|---|---|---|
| 조건 | 교육어 **또는** 창업어 | 교육어 **그리고** 창업어 |
| 결과 | 프론티어 270 → **16,893** | 정밀도 그대로 |

조합 씨앗도 231 → **6,838개**로 늘렸다(업종 42×의도 67, 브랜드 47×20, 지역 233×12, 박람회).

소자본·아이템·추천·비용…)를 전부 지우고 남는 게 없어야 통과. 이렇게 하면 갈비탕프랜차이즈·
개업화분(월 46,960)·스마트팜창업이 OFF 목록에 없어도 '갈비탕'·'화분'·'스마트팜'이 남아 걸린다.

### ⚠️ 네이버는 일예산 < expectCost 면 캠페인을 통째로 멈춘다

`statusReason: CAMPAIGN_LIMITED_BY_BUDGET`. `expectCost` 는 **그 캠페인의 최근 실클릭 비용**이고
입찰가를 바꿔도 안 따라온다 — 새 클릭이 나야 갱신된다. 학원매물·임대는 9/8 클릭 한 번(13,378원)
때문에 expectCost 가 13,378 에 굳어 있어서, 예산 2,600원으로 내리자 **즉시 꺼졌다.**
새 클릭을 받으려면 예산이 13,378을 넘어야 하고, 클릭을 받아야 expectCost 가 내려간다 — 교착이다.

광고주 결정: **예산 13,500 + 입찰 600원.** 예산은 명목이고 진짜 브레이크는 입찰가다
(예측 소진 하루 2,110원). 첫 클릭이 나면 expectCost 가 660원대로 떨어지므로 **그때 예산을
3,000원으로 되돌려야 한다.** 이게 남은 할 일이다.

또 확인한 것: **예산을 올려도 status 는 몇 분 안에 안 바뀐다.** 코딩·SW·로봇을 70→80(expect 77)
으로 올리고 5분간 4번 폴링했는데 계속 PAUSED 였다. 네이버 자체 평가 주기를 타며, 늦어도
KST 자정 롤오버에 재평가된다.
