로컬 상세 산출물: `flyio-backend/reports/haeul_intent_20260909/`. `coverage_verified.json`, `apply_state.json`, `focus_state.json`, `landing_restoration_check.json`, 전체 클릭·검색어 CSV와 조사 결과 Markdown을 참고한다. 원시 보고서·다운로드 토큰·계정 자격증명을 Git에 추가하지 않는다. 환자 식별자나 상담·결제 원문을 이 메모에 넣지 않는다.
