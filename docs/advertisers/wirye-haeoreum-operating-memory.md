**공유예산은 만들지 못했다 — 네이버 API가 생성을 제공하지 않는다.**

`/ncc/shared-budgets` 리소스가 실제로 지원하는 것은 둘뿐이다.

| 호출 | 결과 |
|---|---|
| `GET /ncc/shared-budgets` | 목록 조회 — 정상 |
| `PUT /ncc/shared-budgets/{id}` | 기존 공유예산 수정 — 정상 (키네스에서 검증됨) |
| `POST /ncc/shared-budgets` | 항상 `code 1002 Invalid request` (detail 없음) |
| `DELETE /ncc/shared-budgets/{id}` | `405 Method Not Allowed` |

POST 는 body 문제가 아니다. `SharedBudgetRequest` 의 실제 필드를 타입 프로브로 전부 확인했고
(`customerId` · `name` · `ownerType` · `deliveryMethod` · `dailyBudget`(long) · `budgetLock` ·
`expSearchBudgetRatio`(int) · `sharedBudgetId`(String, Kotlin non-null)), 두 enum 의 허용값도
서버가 직접 알려준 대로 넣었다(`SharedBudgetOwnerType`=[CAMPAIGN, ADGROUP],
`DeliveryMethodType`=[STANDARD, ACCELERATED]). **`dailyBudget` 을 50원 미만으로 주면
"공유예산을 50원~1,000,000,000원으로 설정하세요" 가 나온다** — 파싱과 필드 검증을 모두 통과한다는
뜻이다. 50원 이상으로 올리는 순간에만 detail 없는 1002 가 돌아온다. 위례해오름·키네스·소잠·해울
네 계정 모두 같은 응답이다.

**"다른 세션에서 API로 됐다"는 것은 생성이 아니라 금액 수정이었다.**
`_kiness_20260909_budget_250.js` 는 `PUT /ncc/shared-budgets/{id}` 로 **이미 존재하는** id 세 개의
`dailyBudget` 만 바꾸며, `assert(b,'공유예산 없음 '+id)` 로 사전 존재를 강제한다. 키네스 공유예산의
`regTm` 은 2026-09-08T05:44:38Z 로 그 스크립트보다 앞선다. 이 사실을 "API로 생성이 된다"로
오인하지 않는다.

로컬 `.env` 키(cid 3808925)는 **키네스 441986 은 열리지만 위례해오름 1542287 은 403** 이다.
위례해오름은 fly 프록시를 거쳐야 하고, 프록시 키로 키워드 쓰기(17,717건)와 캠페인 예산 PUT
(`PUT /ncc/campaigns/{id}?fields=budget`, 무변경 검증)은 정상 동작한다 — 즉 계정 쓰기 권한 문제가
아니라 엔드포인트가 없는 것이다.

**남은 절차:** 광고 UI에서 공유예산을 하나 만들면(`도구 > 공유예산`), 그다음은 전부 API로 된다 —
`GET /ncc/shared-budgets` 로 id 를 읽고 `PUT /ncc/campaigns/{id}` 에 `sharedBudgetId`(실재하는
String 필드)를 넣어 캠페인을 붙이고, 금액은 `PUT /ncc/shared-budgets/{id}` 로 조정한다.
플레이스 캠페인 14개를 이 공유예산에 넣으면 CPC 4,000원짜리 플레이스가 풀 전체를 먼저 먹어
파워링크가 굶는다 — 원장이 "플레이스는 손대지 않는다"고 했으므로 제외 상태를 기본으로 본다.

## 신규 키워드 발굴 결과

`/keywordstool` 시드 BFS 2웨이브로 56,499개를 수집했다(로컬 키 cid 3808925).
미등록 44,433개 중 내원의도 + 실볼륨 10 이상은 코어권 39개 · 송파/하남/강동 102개 ·
분당/판교/강남 175개뿐이다. **이 계정은 지역×진료 키워드가 이미 포화 상태다** — 발굴이 아니라
등록된 것 중 무엇에 돈을 쓰느냐가 문제다.

지역 판정은 `_wh2_geo.py` 를 쓴다. `_wh_judge.py` 의 `NEAR` 는 부분문자열이라 발굴 단계에서
`손가락저림`→`가락`, `신장염`→`신장`, `잠꼬대치료`→`대치` 로 오탐한다. 발굴용은 **맨 앞 앵커 +
잔여 문자열에 2글자 이상 진료어**가 있어야 지역형으로 인정한다.

삭제 판정 `_wh2_delrule.py` 는 의학 어근이 하나라도 있으면 살린다. 비의료 블랙리스트를 먼저
검사하면 `전립선염한의원`의 `립`, `청소년한의원`의 `청소`, `성장판검사병원`의 `장판` 이 걸린다 —
**의학 어근 검사를 항상 먼저 한다.** 1글자 어근(`등`·`배`·`눈`)은 `인터넷사업자등록`,
`배민주문접수` 에 걸리므로 쓰지 않는다.
