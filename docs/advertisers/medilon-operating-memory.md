## 실행 중 드러난 함정

- **`--only=keywords`가 그룹 생성까지 수행했다.** 세 단계를 동시에 띄우자 두 프로세스가 같은 이름으로 그룹을 만들려다 `3710 이름 중복`이 쏟아졌다. 이름 유일성 덕에 중복 그룹은 생기지 않았고(라이브 147 = 체크포인트 147, 고아 0), 이후 단계를 분리했다. 단계는 반드시 순차 실행한다.
- **`DELETE /ncc/keywords`는 이미 없는 id가 하나라도 섞이면 배치 전체가 404 `1018 No permission`으로 죽는다.** URL 길이 문제가 아니다(10개 실패, 30개 성공). 100개 배치로는 대부분 통째로 실패해 13시간이 걸렸다. 실패 시 반으로 분할해 내려가고 1개에서도 404면 '이미 없음'으로 기록하는 방식으로 20분에 끝냈다.
- **캠페인 이름으로 키워드를 판정하면 안 된다.** `auto_001_*`를 통째로 무관으로 묶었다가, 그 안의 356개가 정확히 찾던 대출 키워드였다. 28개를 지운 뒤 발견해 문자열로 복구했다. 광고그룹 소속과 통계 이력은 복구되지 않는다.
- **`제휴_PG*`는 무관해 보이지만 건드리면 안 된다.** 키오스크·카드단말기·포스기 계열로, 91일 노출 92만으로 계정 최대다. 별도 사업라인이다.
