## 실행 중 드러난 함정

- **`--only=keywords`가 그룹 생성까지 수행했다.** 세 단계를 동시에 띄우자 두 프로세스가 같은 이름으로 그룹을 만들려다 `3710 이름 중복`이 쏟아졌다. 이름 유일성 덕에 중복 그룹은 생기지 않았고(라이브 147 = 체크포인트 147, 고아 0), 이후 단계를 분리했다. 단계는 반드시 순차 실행한다.
