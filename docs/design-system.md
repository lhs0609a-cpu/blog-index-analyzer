# 블랭크 디자인 개선 원칙

## 사용자 방향 (2026-09-10)

기존 톤앤매너를 유지하면서 완성도를 높인다. 브랜드를 교체하는 리뉴얼이 아니다. 첫 시안의 그린·민트, 영문 blank. 로고, 사이드바는 사용자가 거절했으며 철회했다.

## 유지할 요소

- 블루 `#0064FF`, 보라·시안 포인트와 기존 오로라 글라스 인상
- 상승 막대 형태의 기존 로고와 한글 ‘블랭크’ 워드마크
- 상단 플로팅 내비게이션과 기존 페이지 구조·콘텐츠
- 기존 분석, 계정, 요금제, 광고 운영 기능

## 개선 범위

- 타이포 크기·행간·모바일 줄바꿈, 읽기 쉬운 설명문
- 검색 모드·입력·실행 버튼을 하나의 카드로 구성
- 글라스 깊이는 살리고 색수차·입자·반복 움직임은 절제
- 카드·테두리·그림자의 일관성
- 로그인·회원가입의 집중도, 분석 전 안내
- 모바일 메뉴의 Escape, 포커스 제한·복귀, 스크롤 잠금

`app/workspace.css`는 기존 디자인을 보완하는 스타일이다. 사이드바를 만들지 않는다. `BlankLogo.tsx`는 기존 SVG 형태를 유지하고 React useId로 그라디언트 ID를 안정적으로 생성한다.

## 검증

- 미리보기: http://127.0.0.1:3016
- `python tools/check-design.py`: 화면·입력·이동·모바일 메뉴 검사
- `node tools/check-design-types.cjs`: HEAD 대비 타입 오류 추가 여부 확인
- 스크린샷: `output/design-review/desktop.png`, `mobile.png`
- 기존 전체 타입 오류 90개는 별도 문제이며, 실제 결제·계정 데이터·광고 운영과 운영 배포는 이번 검증 대상이 아니다.
