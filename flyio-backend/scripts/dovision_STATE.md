### 코드 변경 (routers/naver_ad.py)
1. `_DOVISION_ALLOW_TOKENS` 에 **"자격증"** 추가 — 지도사 자격 키워드 전량(90/447)이
   상업 neg-token 에 막혀 있었다. **"대여"** 도 추가 — `50대여성일자리` 안의 부분문자열 오탐.
2. `_DOVISION_TAXONOMY` 에 B2B 중분류 7개 신설: 운영·원생모집 / 지도사·자격입문 /
   교사·강사모집 / 가맹모집·상담 / 창업비용·수익성 / 인허가·절차 / 주부·경단녀.
   교육창업은 소분류를 5개(타업종교육창업 포함)로 세분.
3. 중분류에 **gate 토큰** 지원 — 주부·경단녀는 페르소나 앵커(주부·경단녀·40대…)가 있어야
   매칭. 없으면 '부업' 하나로 직장인부업까지 주부 캠페인에 들어온다.
4. `POST /keyword-pool/admin/insert-exact` 신설 — 검수된 목록을 **연관확장 없이** 삽입.
   기존 `domain_skipped`/`failed` 행은 pending 으로 requeue(게이트가 바뀌었으므로).

## 2026-09-04 작업: 소재·확장소재 전 그룹 전개 — 계정이 처음으로 '켜졌다'

표본 30개 그룹을 조회했더니 **전부 `ads=0`** 이었다. 키워드 7만 건을 등록해 놓고도 계정
노출은 0 이었다 — 소재가 한 그룹(`grp-...070283465`)에만 있었기 때문. 이 작업은 "소재 추가"가
아니라 **6,015개 광고그룹 전량을 노출 가능 상태로 만든 것**이다.

| 전개물 | 원본 | 결과 |
|---|---|---|
| RSA 소재 (헤드라인 8 · 설명 4, → `/franchise/info`) | `nad-a001-01-000000576133214` | 6,015/6,015 |
| 파워링크 이미지 확장소재 (640×640, 비즈채널 `bsn-...14539191`) | `ext-a001-01-000000488842010` | 6,015/6,015 |

검증: 표본 300개 그룹 재조회 — RSA 소재 1개·확장소재 1개씩 정확히, 전부 `APPROVED`,
중복 0. 스크립트 `_dv_apply_ext.py` (체크포인트 `_dv_done_{ad,ext}.json`), 검증 `_dv_verify.py`.

### 배운 것
1. **naver-raw 프록시는 동시성 5 에서 HTTP429 를 뱉는다.** 1차 패스에서 소재 129건·확장 499건이
   429 로 떨어졌다. 네이버가 아니라 fly 앱 쪽 레이트리밋이라 영구 거부가 아니다 —
   **동시성 2 로 낮춘 재시도 1라운드에서 628건 전부 성공(실패 0)**. 대량 쓰기는 처음부터 2로.
2. 체크포인트에 **성공한 gid 만** 적재하는 구조라 재실행이 곧 재시도다. 중복 생성 없음이
   표본 300개로 확인됐다(모두 정확히 1개씩).
3. RSA 소재 복제는 `assets` 를 `{assetType, assetData:{text}, linkType}` 로 재구성해 보내면
   네이버가 **기존 APPROVED 에셋(`ast-...`)에 그대로 붙여 준다** — 텍스트 재심사가 없다.
